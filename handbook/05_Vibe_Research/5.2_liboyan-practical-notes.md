## Background and Trends of Vibe Research / Vibe Coding

### The Evolution of Web Coding

- **Origin of the concept**: Last February, a co-founder of OpenAI first proposed the concept of "Vibe Coding", sparking a programming revolution; last November, Vibe Coding was named Collins Word of the Year.
- **Current scale**: According to statistics from the CEO of a world-famous startup accelerator, 95% of the code in 25% of startups is generated by AI.
- **Impact on research**: Vibe Coding gives people outside AI the ability to turn ideas into products, improves research coding efficiency, and shortens the paper publication cycle; in 2026 it is expected to cover the entire research workflow.

### The Components of Vibe Research

Boyan Li believes Vibe Research can be divided into three parts, covering the whole process of research from proposing an idea to code implementation, paper writing, and figure drawing:

1. **Vibe Coding**: code implementation
2. **Vibe Figure**: paper figure drawing
3. **Vibe Writing**: paper writing

## Vibe Coding Tools and How to Use Them

### Tool Selection

Boyan Li recommends using frontier models and good tools, and suggests choosing powerful tools even if they may require payment:

| Tool | Features | Use Case |
|---|---|---|
| **Cursor** | An AI-native IDE based on VS Code with the lowest barrier to entry; supports calling different frontier models; rich plugin ecosystem (Git Lens, etc.) | First choice for beginners, team collaboration |
| **Codex** | An AI coding assistant released by OpenAI, with good GitHub integration | GitHub users |
| **Claude Code** | Powerful, with a slightly higher barrier to entry | Advanced use |

**Notes on using Cursor**:
- Download and install it from the official website. It supports calling different frontier models, but using strong models may require payment and a proxy
- In the settings, change the HTTP compatibility mode to 1.1 in order to access the world's frontier models
- It supports a rich plugin ecosystem, so install plugins as needed

### Mindset Principles of Vibe Coding

- **Do not do by hand what AI can do**: trust AI, but review the code yourself
- **Let the goal lead the conversation**: be goal-oriented, context is king, and keep the AI from writing irrelevant code
- **Subtractive thinking / the MVP mindset**: do not have the AI complete a large amount of code in one interaction, and follow the minimum viable product principle in development

### Vibe Coding Techniques and Tips

1. **Plan first, execute later**: use Plan Mode to have the AI produce a plan, discuss it with the AI to settle on an approach, and then execute
2. **State clear requirements**: including what to implement, functionality, inputs and outputs, code conventions, etc.
3. **Move in small fast steps**: have the AI implement the smallest functional unit, and do Code Review and testing promptly
4. **Manage context**: split complex tasks into subtasks and supply any missing context
5. **Provide error-correction context**: when the AI makes a mistake, provide enough context to help it fix the problem
6. **Use git fluently**: do version control and keep the ability to roll back

## Tips for Paper Writing and Figure Drawing

### The Vibe Figure Workflow (Four Steps)

**Step 1: Figure design**
Tell the AI the logic of the paper (for example by chatting with GPT) and have it propose multiple options for drawing the main figure (such as options a to f), and choose the best one.

**Step 2: Generate the prompt**
Based on the chosen drawing approach, have GPT or Gemini generate an image-generation prompt that meets paper submission standards (for example, using English fonts and matching SML Oral quality).

**Step 3: Generate a draft sketch**
Use the prompt in the Gemini web app or in a text-to-image model such as Nano Banana Pro to generate the image. The generated image is a draft sketch; if the prompt meets expectations, the sketch quality is generally not bad.

**Step 4: Draw the vector figure**
Use a drawing tool to draw the vector figure with the sketch as a reference (raster images generated by Gemini or Nano Banana cannot be used directly in a paper):
- Recommended tools: **Figma**, **OmniGraffle**, **PPT**; no tool is better or worse than another, just use one fluently
- Icon sources: download from icon sites, or generate with GPT (you can have the AI redraw an icon in the style of an existing one)
- Converting PNG to vector: you can use tools such as Edit Banana, or draw by hand in Figma/PPT; SVG is the most standard vector format

### Vibe Writing Guidelines

- **Never** copy AI-generated paper content directly into your own paper; you are responsible for the accuracy of the content and the AI rate
- **Never** let AI write the references or cite freely
- **Correct usage**: give enough context (the research problem background, method, limitations, challenges, experimental data, figures from the paper, etc.) and let AI assist with the writing approach; but a human must verify the accuracy of every sentence

## Q&A Session

**Q: How can I use large-model AI to come up with feasible research ideas?** (asked by Yuyu Luo)

Boyan Li's view: for now, AI's ability to directly propose highly feasible ideas is limited, but you can discuss specific problems with AI in depth. For example, on the problem of reducing the schema cost of Text-to-SQL, by repeatedly "grilling" the AI's proposals and steering it with your own experience, there is a good chance of getting the AI to propose a feasible idea.

**Q: How exactly do you handle web icons? Can PNG be converted to SVG?**

- You can have the AI redraw an icon in the style of an existing one
- PNG icons can generally be placed in a figure, but for large figures we recommend converting to SVG vector format
- Tools for converting PNG to SVG: Edit Banana (recommended by Prof. Luo), VI VectorRise, and other vectorization tools; you can also draw by hand in Figma or PPT
- Images downloaded from the Gemini site are PNG; PDF/SVG are the vector formats

**Q: Copilot performance and model selection?**

- In Copilot you can choose different models in the settings; no AI tool is absolutely good or bad
- We recommend using a mature IDE or CLI (rather than a plugin), because an IDE has better context engineering
- If you use the Copilot plugin, you can choose stronger models such as Gemini Pro and Claude Code 4.5/4.6

**Q: Does AI have the ability to do closed-loop research?**

Boyan Li's view: AI currently lacks a complete closed-loop research capability, but you can try distilling the paper publication cycle into context for the AI to learn from, and explore the possibility of it proposing more promising ideas.
