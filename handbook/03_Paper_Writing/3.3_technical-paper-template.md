# 3.3 Paper Writing: Thinking Template for Technical Full Papers (for Discussion)

## How to Use

Readers can use the table in this template during topic discussions, progress reviews, and manuscript writing to fill in (instantiate) their research ideas item by item, which helps with alignment, retrospectives, and collaboration.

**How to use it?** Copy this template into a standalone document and fill in the specifics item by item in your copy.

## A Thinking Model for Writing the Paper Introduction (the Introduction Is a Condensed Version of the Whole Paper)

Generally speaking, the Introduction can be regarded as the "compressed version" of the whole paper: use the least space to make the research subject clear, explain thoroughly why the problem is hard, and make clear why our method is necessary. A clear writing organization is as follows. First, use a typical application scenario / running example to introduce the research background and needs. Next, summarize representative existing work and distill the main limitations it exposes under key assumptions, data characteristics, workloads, and system constraints (usually no more than 3 points). On that basis, further characterize the intrinsic properties and hard constraints of the problem (for example scale, dynamism, heterogeneity, end-to-end overhead, correctness/consistency requirements), so as to naturally derive the research goal or problem definition this paper addresses (Our Goal / Problem Formulation), or the core insight (Key Idea) that supports the solution design. Then, state clearly the key challenges in achieving this goal (usually no more than 3 points) and explain why directly applying or simply extending existing methods does not work. Finally, give a method overview (overall framework and key modules) that corresponds one-to-one with the challenges, and close with the contributions: the problem definition/setting (if any), the system/framework design, 1-2 key technical points, and thorough experimental evaluation and analysis.

### Quick Positioning: What Type of Paper Is This?

**Technique paper (a new method that solves an existing problem)**
- Main axis: Key Idea / Mechanism
- Goal: one sentence is enough

**Propose a New Research Problem/Setting (a new problem / new setting / new task)**
- Main axis: Our Goal / Problem Formulation (the problem definition itself is a contribution)
- Key Idea: serves as the support for "why this definition is reasonable/feasible"
